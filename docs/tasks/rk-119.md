# RK-119 动画与特效验收台（首版：资源动画）

> 项目负责人已确认参考图交互方向及任务范围。已登记待依赖；RK-074 完成验收后安排，不打断当前开发。

| 项 | 内容 |
|---|---|
| 优先级 / 里程碑 | P1 / M1 开发工具 |
| 依赖 | RK-073（已通过）；RK-074（正在开发，先通过验收再开本任务） |
| 分支 | `rk-119`，从排期时最新 main 创建 |

## 目标
提供可以直接打开的开发验收界面，复用正式 PNG/帧元数据，便于负责人和项目经理检查原尺寸轮廓、动画节奏、逐帧姿态、锚点和灰度形状，不必为每次观察重新运行截图脚本。

首版接入 RK-073 的角色/敌人动画及 RK-074 的静态资源。后续魂印、共鸣、攻击和受击效果由对应实现任务将真实场景接入此验收台；本任务不复制尚未实现的效果，也不把静态图冒充特效演示。

## 界面方向（按负责人参考图细化）
- 中央为俯视地面预览区；右侧为“对象/角色 → 动作 → 特效”选择，底部为播放控制与帧信息。对象选择包含玩家、普通敌人、精英，以及静态资源类别；动作列表随所选对象变化。
- 点击对象、动作即切换真实资源；特效列表显示实际已接入项，支持单次触发、循环重播、清除。尚未接入时明确显示“未接入”，不生成假效果或伪造可用状态。
- 第一版只让 RK-073 动画与 RK-074 静态资源可选；未来 death/hurt/attack 和魂匣攻击、魂印、共鸣等随对应任务接入，不因参考图出现按钮就提前实现玩法。
- 中央使用顶视地面网格、脚底锚点和可切换的纯展示靶子标记；碰撞/攻击范围仅在接入项提供真实几何数据时显示，否则明确不可用。无需平台、重力、jump/fall，也不在验收台独立复制战斗判定。
- 以操作方便为目标：对象选择后保留兼容动作，否则回到idle/单帧；特效切换先清理旧实例，连续触发不会残留。键鼠操作明确，当前对象、动作、特效和播放状态始终可见。
- 参考图右侧的 death/hurt/attack 等“优先级”不是首版硬编码规则。本任务是主动选择的资源验收工具；游戏动画状态优先级由未来真实动画控制任务定义，若需要验收则调用该正式控制器。

## 要做的
1. 新增独立调试场景 `game/app/dev/asset_review_lab.tscn` 和同名 `.gd`，主脚本 `class_name AssetReviewLab`，继承 Control。复杂时可拆分辅助脚本于同目录，每文件不超过400行；公开方法有类型及 `##` 说明。
2. 不改 project.godot 主场景；用编辑器单独运行场景，或 Godot `--path game res://app/dev/asset_review_lab.tscn` 打开。启动时检查 OS.is_debug_build，release 不进入验收台；不增加正式游戏菜单入口。
3. 从 `game/assets/sprites/greybox/rk073/` 和 `rk074/` 的正式生产 JSON/PNG 建立只读目录，不读取临时截图、不依赖仓库外绝对路径，也不要求 app 运行时读取 art 源目录。RK-074 数据格式以验收后实际文件为准，适配在本任务中完成，不修改资源元数据来迁就界面。
4. 以“对象/角色、动作、特效”三级选择为主；已有资源支持类别、id、动作、品阶筛选，未实现特效明确未接入；显示源 PNG 路径、原生尺寸、帧数、当前帧、该帧时长和 pivot。切换资源立即重置到第0帧，不残留上一个资源的播放或显示状态。静态资源显示“单帧”，不播放假动画。
5. 提供播放/暂停、上一帧/下一帧、回到首帧、循环开关、0.25/0.5/1/2倍播放速度。逐帧操作自动暂停并严格移动一帧，帧号按明确的0基或1基显示。只改变验收台自身播放时钟，不改 Engine.time_scale 或游戏模拟状态。
6. 按元数据每帧时长播放，不把所有资源强制设成同一 fps。帧矩形、透明间隙和 pivot 均从实际元数据读取，防止切到间隙或锚点跳动。
7. 同时提供1倍和3倍预览区，nearest整数像素展示；验收台本身显示放大是查看工具，不修改生产素材或游戏实体缩放。640×360 基准界面不能遮住主要控件；可使用滚动列表，窗口放大后布局可用。
8. 背景在区域1地面 #1C1B26、灰底、透明棋盘之间切换；资源可以切换原色、灰度、纯黑剪影。变换只发生在预览材质中，不覆盖生产 PNG；剪影处理能排除 RK-073 固定投影色，灰度图保留主体形状。
9. 可切换显示画布边框、主体框（有元数据时）、pivot十字和对齐基线。支持隐藏名称只显示编号，编号答案可在侧栏单独查看，便于原尺寸盲看辨识。
10. 提供“导出当前画面”按钮，写入明确显示的 user://review/ 目录，并打印可定位的绝对路径及当前资源/帧号/速度。只能写预览文件，不能写源资产。截图输出仍需人工判断，不显示自动“剪影通过”。
11. 正常借鉴现有 AnimatedSprite2D/AtlasTexture 或自有预览时钟；不能创建第二套资源导出、玩法模拟或图像生成框架。为后续真实特效留出同一场景内的选择和触发位置，首版空列表显示未接入；不提前设计未知特效 API，也不提供空按钮冒充已实现效果。
12. 缺图、坏 JSON、越界帧矩形和缺少必要字段时，界面显示具体文件及原因，停止该资源播放，仍可切到其他正常资源；不能闪退、无限循环或悄悄换成其他图片。

## 验收标准（backlog）
- 界面包含对象/角色、动作和特效选择；现有资源可即时切换，未实现特效清楚显示未接入。独立调试界面能选择 RK-073 动画与 RK-074 静态资源；播放/暂停、逐帧、倍速、1倍/3倍、背景/灰度/剪影和截图均能操作；读取生产元数据，逐帧矩形与pivot正确；release无入口且生产资源不被修改。

## 测试与自检
1. `python3 tools/run_tests.py` 全部通过，不修改现有测试运行器；现有 art_check 仍全部通过。
2. 提交说明给出场景打开命令、UI操作步骤和至少1张实际运行截图；以真实界面操作结果和引擎输出为主，不要求为每个按钮写镜像单元测试。
3. 选骑士run：默认按83ms帧时长播放；暂停后等1秒帧号不变；按下一帧只走一步；循环开启时末帧能回首帧，关闭时末帧停止；首帧按钮回到第0帧。
4. 选另一套动画，再选 RK-074 单帧T4：切换无旧图残留，主体中心对齐，显示单帧状态；T1—T4的画布和主体区别能查看。
5. 原色/灰度/黑剪影和三种背景均可切换；7标签图标1倍尺寸可看；隐藏名称模式不泄露类型名称到预览区。
6. 独立对照同一帧的1倍/3倍截图，3×3像素块一致，无平滑插值；导出成功后输出实际路径，PNG可打开。
7. 临时破坏一份资源JSON的帧矩形：界面显示具体错误并停止该资源播放，其他资源仍能选择；恢复后重新打开正常。此项故意改坏不得提交。
8. 临时把逐帧按钮改为自动播放而不是单步：暂停后单步检查必须暴露错误；恢复。检查 git diff 不包含资源、project.godot 或用户既有格式变更。
9. 补充一个独立 headless smoke 探针验证场景可加载及目录/帧元数据读取（放 tools/acceptance/rk119_*）；Godot进程用Python subprocess timeout不超过45秒，先导入，扫描引擎错误，输出 `RK119: passed`。按钮和显示效果仍实际操作验收，不以smoke代替。
