# RK-002 创建 Godot 工程

| 项 | 内容 |

## 目标
在 `game/` 建好 Godot 4.7 工程：像素显示设置、强制类型、架构规定的目录。后面所有任务都在这个工程里做。

## 要做的
1. **工程**：`game/project.godot`，工程名"魂匣地牢"。
2. **显示设置**（style-bible 1.2 节）：

   | 设置项 | 值 |
   |---|---|
   | `display/window/size/viewport_width` / `viewport_height` | 640 / 360 |
   | `display/window/size/window_width_override` / `window_height_override` | 1920 / 1080 |
   | `display/window/stretch/mode` | `viewport` |
   | `display/window/stretch/scale_mode` | `integer` |
   | `rendering/textures/canvas_textures/default_texture_filter` | Nearest |
   | `rendering/2d/snap/snap_2d_transforms_to_pixel` | 开启 |
   | `rendering/2d/snap/snap_2d_vertices_to_pixel` | 开启 |
   | 贴图导入默认值 | 关闭 Mipmaps，压缩模式 Lossless |

3. **强制类型**（architecture 8.1 节）：`[debug]` 段加 `gdscript/warnings/untyped_declaration=2`。
4. **目录**（architecture 第 2 节）：建 `data/`、`sim/` 及其 7 个子目录、`view/battle/`、`view/ui/`、`view/fx/`、`app/`、`assets/sprites/`、`assets/fonts/`、`assets/audio/`、`tests/lib/`、`tests/data/`、`tests/sim/`。空目录放 `.gitkeep`。
5. **启动场景**：`app/boot.tscn` 加脚本 `app/boot.gd`，设为主场景。画一张 640×360 的像素测试图，用来检查缩放：
   - 背景为区域 1 地面色 `#1C1B26`
   - 每隔 16 像素画一条 1 像素宽的网格线，颜色 `#3D3850`
   - 左上角画一个 4×4 的棋盘格（1 像素一格，黑白相间）
   - 用 `_draw()` 画，不用图片文件。脚本所有变量和函数都写类型
6. **README.md**（仓库根目录）：项目一句话简介、目录说明（指向 architecture 第 2 节）、怎么打开工程。测试命令留到 RK-003 再写。

## 不要做的
- 测试框架、`tools/run_tests.py`（那是 RK-003）
- 任何玩法代码

## 自检步骤
1. 导入无报错（用 Python 加 120 秒超时运行）：
   `"$GODOT_BIN" --headless --path game --import`
   退出码为 0，输出里没有 `ERROR` 和 `SCRIPT ERROR`。
2. 强制类型生效：临时在 `sim/` 写一个缺类型的脚本 `func f(x): return x`，用 `--check-only -s` 检查，应报 "has no static type"。检查完删掉，不要提交。
3. `git status` 里没有 `.godot/`。
4. 截图检查（如果你能运行带窗口的 Godot）：1920×1080 下，网格线每条正好 3 像素宽，棋盘格每格 3×3，边缘没有模糊。做不到就在汇报里写明，由项目经理检查。
