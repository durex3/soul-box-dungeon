> 项目负责人已确认：T3/T4 主体8/10像素分别使用10/12像素画布容纳装饰，7标签图标统一8×8，本任务仅静态灰盒；仅灰盒 box 新增12×12尺寸支持。

## 目标
按 backlog RK-074、style-bible 5.1/5.2/8/15 节，制作 12 个魂匣各 4 阶光球、5 个拾取物图和 7 个标签图标，共 60 个静态灰盒 PNG 及元数据和原生源，供后续系统接入。重点是品阶结构、功能色、形状辨识和稳定锚点。

本任务是 M1 灰盒，不提前制作 M3 RK-092 正式魂匣美术/攻击特效或 RK-093 正式 UI，不做运行时环绕、漂浮、粒子、吸取、碰撞和动画控制器。正式风格锚点由 RK-086 开始。

### 已确认的口径
1. 区分主体与导出画布：T1 主体/画布 6×6；T2 主体/画布 8×8；T3 主体 8×8、画布 10×10，留出 2 像素拖尾；T4 主体 10×10、画布 12×12，留出外围粒子。主体尺寸按 5.2 节，装饰不靠裁切塞入主体画布。尺寸表 4.1 的“8×8 光球”是一般规格，本任务具体品阶按 5.2 及此确认口径执行。
2. 7 个标签图标统一 8×8（5.1 节允许 8/12）；本任务仅静态图，T4 粒子以静态点簇表达结构，运动由后续表现层任务实现。拾取物的动态同样不在本任务实现。
3. 仅对项目实际 `game/assets/sprites/greybox/` 下的 `box_` 检查新增 12×12 单帧尺寸支持；非灰盒 box 规则不变，实际每阶尺寸和静态帧数由本任务验证脚本严格检查。角色既有两帧规则不变。

文档冲突：5.2 的“8×8 加拖尾 / 10×10 加粒子”未区分画布与主体；现有 art_check 只接受 box 单帧 6/8/10。上述口径已获负责人确认，按本任务执行，不由开发自行猜测。

### 2. 像素规格
- 只用 ally 色板，不使用敌弹品红、预警红、纯黑或纯白大块；不修改现有色板。alpha 仅 0/255，禁止抗锯齿、半透明、烘焙地面或标签文字。
- 标签主色：fire #FF8A1F、frost #A8EEFF、lightning #4F7BFF、mechanical #C9A25E、undead #5FD38D、holy #FFE8A3、melee #B8C2CC。经验 #B48CFF、魂晶 #FFC93C、能量 #3DF2C5。
- 单标签光球取其标签色；双标签光球的主体按 5.2 分为左/右两半，分别对应表中第一/第二标签，不反转、不只画成单色。5.1 的具体攻击造型不在本任务实现。
- 品阶不换成武器品质色：T1 实心；T2 增加 1 像素亮芯；T3 保留亮芯并有 2 像素拖尾；T4 原生绘制更大主体和分离的外围粒子点。明暗层次只为结构辨识，不靠单纯换色表示品阶。
- 所有尺寸原生绘制，禁止运行时或离线缩放 PNG 充当新品阶。主体、拖尾和粒子均在画布内，T3/T4 的 pivot 指向主体几何中心，不能因外围装饰改变环绕中心。
- 图标轮廓严格采用：火苗、冰晶、闪电、齿轮、骷髅、圆环、交叉双剑。7 个图标转灰度后仍须靠结构辨识；再做等亮度单色辅助图，防止只是灰度亮度不同。
- 拾取物无装饰投影和外扩粒子，不用与标签相同的圆形通用图替代菱形/六边形/水滴。

### 3. 原生源、元数据与导出
- 每个 PNG 一个同名 `.aseprite` 源，放 `art/source/rk074/`，共 60 个；真实可编辑，不是重命名 PNG。源文件为单帧，至少主体层；T3/T4 的拖尾/粒子另放 Decor 层。
- `manifest.json` 列出 file、category、id、tier（适用时）、tags（保持顺序）、canvas_size、body_rect、pivot、source 和 palette。同名生产 JSON 记录图片大小、单帧矩形、主体框及 pivot，指向原生源。无碰撞/伤害/价格等玩法字段。
- pivot 相对单帧；主体中心为 (body_rect.x+w/2, body_rect.y+h/2)，拾取物/图标为画布中心。不把左上角或含拖尾的整图中心误作主体中心。
- `tools/build_rk074_assets.py` 用 Python 3.9 标准库调用 Aseprite 批处理，仅从源导出，不读取生产 PNG 生成，不覆盖可编辑源；支持 ASEPRITE_BIN 和临时输出目录参数，子进程加超时。可参考 RK-073 但不要改旧任务脚本。
- 生产 PNG、JSON、Godot `.import`/`.uid` 提交；临时预览不进生产目录。导出和重导出不 trim、不缩放，元数据路径规范为相对路径/文件名。
- 在 `art/ai_log.csv` 追加恰好 60 条手绘记录，指向原生源，注明灰盒原生绘制/Aseprite 导出，保留原有 36 条及修改历史。不使用 AI。
