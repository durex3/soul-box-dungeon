## 目标
补齐 RK-005 验收记录里的静态检查漏洞，依据 architecture 4.6 节。只改 Python 检查工具和测试，不改 Godot 玩法或随机派生算法。这是收紧检查，不算放宽测试。

## 要做的
1. 修改 `tools/lint_layers.py`，保留 `lint(root: Path) -> list[str]` 接口和 `文件:行号:原因` 诊断格式。
2. 在现有全局函数检查中补 `seed()`、`rand_from_seed()`、`randfn()`，只检查无接收者的调用。`rng.randfn()` 合法，空格、Tab、点号与方法名之间换行也按成员调用处理。不得误报 `my_seed()`。
3. 禁止任意接收者的 `.shuffle()`、`.pick_random()`，包括点号前后的空白和换行。不做类型推断，`items.my_shuffle()` 不报错。
4. 精确路径 `sim/core/run_rng.gd` 之外，禁止将内置类直接赋值：`var C = RandomNumberGenerator`、`var C := RandomNumberGenerator`、`const C = RandomNumberGenerator`、`C = RandomNumberGenerator`，包括带类型的声明和等号后换行。直接赋值时就报错，不必等到 `C.new()`。已有直接 `.new()` 检查保留。允许 `var rng: RandomNumberGenerator` 和成员取数。无需通用数据流分析、反射分析或追踪容器/函数参数。
5. 沿用注释和字符串屏蔽，例外按路径判断。只扩展模拟层规则，data/view/app/tests 不新增这些限制。错误说明应区分全局入口、数组随机方法、生成器类别名。
6. 修改 `tools/test_lint_layers.py`。只用 Python 标准库，不新增依赖，不改现有测试运行协议。

## 测试
汇报按以下顺序对应测试方法名：
1. 3 个新增全局函数逐个报错；现有全局函数仍报错；`rng.randfn()`、`rng.seed = 42`、`my_seed()` 合法。
2. 两种数组随机方法逐个报错；空格、Tab、换行变体报错；相似方法名不误报。
3. 第 4 条列出的 5 类直接赋值、带类型及换行变体报错；另加赋值后 `C.new()` 的组合例子。只要求赋值处至少有一条诊断。
4. 精确路径允许生成器直接创建和类别名；其他目录同名文件、相似文件名、伪造 `class_name RunRng` 均无例外；该精确路径仍禁止全局函数、数组随机方法和 randomize。
5. 新增违规写法放在注释、普通字符串、多行字符串中均不报错；类型注解不误报；包含空行的样例诊断行号正确。
6. data/view/app/tests 中的新增写法不触发新增规则。
7. 全量工具及 Godot 测试通过，既有规则保持有效。

## 自检步骤
1. `python3 tools/run_tests.py` 退出 0，末行 `TESTS: N passed, 0 failed`。
2. 逐项临时移除新增的全局函数、数组方法、类别名检查，对应工具测试必须失败；逐项恢复。
3. 临时在 `game/sim/core/` 添加违规脚本，分别放入全局 `randfn(0.0, 1.0)`、`items.shuffle()`、`var C = RandomNumberGenerator`。每次 `python3 tools/lint_layers.py` 均退出 1，输出正确文件和行号。该步骤只运行静态检查，无需导入这些临时片段。
4. 删除临时脚本，恢复所有故意改坏内容，再跑完整测试。
5. `git diff --stat` 仅本任务工具和测试；按 architecture 第 10 节提交，列出测试对应关系。
