- RK119范围：`asset_review_lab.gd`、`review_widgets.gd`、`review_canvas.gd`及必要场景引用。包括Button/CheckButton/Label、OptionButton及其PopupMenu条目、LineEdit输入/placeholder、tooltip、动态状态/错误/导出提示，以及自绘caption、1×/3×标注和“展示靶”。不能留下ThemeDB.fallback_font自绘入口。

按以下顺序汇报：
1. 两场景冷启动实际绑定FontFile、禁系统回退及12px字号；逐个核对所有实际字符串的字形覆盖，输出去重文本/码位清单。检查PopupMenu条目、placeholder/tooltip、自绘文字的实际字体，不能只递归Button/Label。字体配置和has_char都要检查，不能以字符串UTF-8或MCP无错替代。

3. RK012实际操作：初始状态、0/+50%重建、移动后坐标/步数更新，两个窗口下文字无方框、截断、互相覆盖或操作按钮被挤出屏幕。禁止通过改Sim状态实现字体验收。
4. Godot图形进程640×360及1280×720下导出实际PNG到 `/private/tmp/rk120-checks/` 或指定目录，冷启动、菜单展开、展示靶、长状态/错误提示、两移动加成状态均留证。检查控件/文本几何并查看实际字形；图形事件检查真实操作命中，明确合成事件而非实物鼠标/手柄试玩。
