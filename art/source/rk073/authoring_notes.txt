RK-073 / Codex / 2026-10-30

Native source of truth: the 18 .aseprite documents in this folder.
Each document: RGB/sRGB, separate Body and Shadow layers, four independent cels per layer,
idle tag frames 1-2 at 167 ms; run tag frames 3-4 at 83 ms.
The per-frame foot pivot is (canvas_width / 2, canvas_height - 3).

Initial construction: draw_greyboxes.lua uses native target-grid pixel primitives.
Normal and elite silhouettes have separate coordinate recipes. Elite limbs, proportions,
and clusters were arranged independently; no resized raster or multiplied normal coordinates.
Body outlines are dark for normal units and warning red for elites. Shadow pixels are opaque.
The ally/master source palette is embedded using the project's existing GPL palettes.

Editing workflow: open the .aseprite document in Aseprite and edit it normally.
Export only: python3 tools/build_rk073_assets.py [--output-dir PATH]
This exporter reads native documents; it never calls the authoring script or writes sources.
Optional binary override: ASEPRITE_BIN=/path/to/aseprite.
The authoring helper refuses to overwrite any existing document; it is historical construction
support, not the ordinary build path. audit_sources.lua opens sources read-only for validation.

              python3 tools/run_tests.py
